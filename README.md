# gh-copilot-calculator

A simple calculator built with HTML, CSS, and JavaScript using GitHub Copilot.

This project is a lightweight browser-based calculator with a clean interface and basic arithmetic operations. It is designed as a small front-end app to demonstrate how GitHub Copilot can help generate a working UI and interactive logic.

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Number entry with decimal support
- Clear/reset button
- Responsive single-page layout
- Read-only display for the current expression and result
- Basic error handling for invalid calculations

## Project files

- `index.html` — main calculator layout and page structure
- `styles.css` — calculator styling and layout
- `script.js` — calculator logic and button interaction handling

## Run locally

1. Clone or download this repository.
2. Open `index.html` in a browser.
3. Use the calculator buttons to enter numbers and operators.
4. Press `=` to evaluate the expression.
5. Press `C` to reset the display.

## Example usage

- `7 + 3 = 10`
- `12 / 4 = 3`
- `9 * 6 = 54`

## Notes

This app intentionally keeps the implementation simple and focused on the core calculator experience. It is a good starting point for learning front-end JavaScript, DOM interaction, and GitHub Copilot-assisted development.
